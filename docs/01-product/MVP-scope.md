# Kakomon · MVP 功能范围（MVP_SCOPE）

**版本：** v1.0  
**日期：** 2026-05-14  
**用途：** 明确 V1 必做 / 可延后 / 不做，防止排期膨胀

---

## 一、判断标准

| 标记 | 含义 |
|------|------|
| **M**（Must） | V1 上线必须包含，缺少则产品不成立 |
| **S**（Should） | V1 可包含，时间允许做，不做也不阻碍上线 |
| **W**（Won't） | V1 明确不做，推后至 V2 或后续迭代 |

## 六、跨模块 Shared Services

## 七、V1 上线内容最低门槛

**以下数据量不足，产品将是空壳，无法正式上线。**

| 内容 | 最低量 | 当前状态 | 负责方 |
|------|--------|---------|--------|
| 大学数据（14 所）| 完整 | 原型已有，需后端录入 | 运营 |
| 过去问题目 | ≥ 200 题 | 原型 mock 数据，需真实内容 | 运营 + 研发（导入脚本）|
| 标准解析 | 与题目一一对应 | 无 | 运营（AI 辅助生成）|
| 参考书章节匹配 | ≥ 100 题有匹配 | 无 | 运营 + 研发（标注工具）|
| 举一反三关联 | ≥ 50 组 | 无 | 研发（pgvector 预计算）|
| 论坛种子帖子 | ≥ 50 帖 | 无 | 运营发布 |
| 教授信息 | ≥ 30 位（3 所重点校）| 原型部分有 | 运营 |

> **建议 Phase 0（第 1 周）即启动内容导入，独立于研发排期推进。**
