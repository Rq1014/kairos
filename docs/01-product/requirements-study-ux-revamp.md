# 需求整理：学习 / 大学 UX 改版

> 本文件汇总用户在「学习/大学 UX 改版」任务中提出的全部需求（原始 prompt 整理），便于回溯，防止上下文丢失。
> 来源：feat/study-ux-revamp 分支，2026-06-09 对话。

---

## 一、大学评分页面（app/university/[id].tsx）

1. **不要写「弱点重叠度」**（大学相关页面均不出现该指标）。
2. **修考难度评分改用满分 5 分制**的方法评估。
3. 如果加入**雷达图**能降低显示面积 / 拥挤程度，可以添加。
   - 用户最终选择：**装 react-native-svg 做真正的雷达图**。
4. **增设打分按钮**，允许个人评分。
   - 注意：不同学校考的科目不一样，针对「入学难度」这类维度直接打分有困难，
     所以**改用一些通用的评估指标**来打分。
   - 补充确认：因为都是个人打分，所以**「资料丰富度」维度保留没有问题**。
5. **Bug：点开东京大学界面后，「概览 / 过去问 / 评分」这一栏无法完整显示**，是明显的 bug，需修复。

---

## 二、搜过去问（app/search.tsx）

6. 「**学校预览 / 按学校浏览**」这里要能**显示其他学校**，而不是仅有 6 个学校的框图。
7. 不同学校有不同的专攻，做的题目也不一样。需要做成
   **学校 → 专攻（研究科） → 习题** 的三级结构，这样才合适。

## 三、参考书（先隐藏，未来再提供）

8. 专题学习等处的**参考书**，目前先不要提供，未来升级时可以提供，所以**都先隐藏住**。

## 四、专题学习（app/topic-study.tsx）

9. 显示线性代数时，难度评分等内容**太宽**，导致屏幕能完整显示的题太少，需要改版。
10. **不再显示「系统/大家评分」有多少**，而是直接在**题目名称最右侧**用
    「难 / 极难 + 评分」的方式展示，使**同一页显示的标题变多**。

---

## 五、模拟考试（app/mock-exam.tsx）

11. **左右间距错误**：左侧宽度过大，右侧不能更有效显示。要把**左侧改小一点**（用户强调此项严重，需切实改动）。
12. 逻辑上**本版本不存在「已选科目：数学/情报」模式**，需去掉。
13. 新的选题（模拟考试）逻辑：
    - **点击添加 → 选择大学 → 选择研究科**，由此确定左侧的学校和研究科。
14. **右侧显示**：xxxx 学校 xxx 研究科。
15. **东大（目标校界面）有问题**：在下面**目标校灰色字的位置，要显示所选择的专攻**。
16. **非会员**也应享有免费额度：**备考设置中选择的 3 所学校，都应免费开放最近 3 年的题目**
    （此前实现遗漏，需补回）。

## 协作约定（来自 CLAUDE.md）

- 每次执行任务前，先在仓库根目录 `tasks.md` 写 checklist，按 `[ ]` / `[x]` 跟踪，完成一步即更新。
- 框架：Expo + expo-router（React Native）。
- 主题/样式：`@/constants/colors`（明暗主题，默认 light）、`@/constants/typography`、`@/constants/spacing`。
- 数据：`@/api/*`（react-query），mock 兜底数据在 `@/mocks/data`。
