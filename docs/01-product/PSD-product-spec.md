## 一、产品定位

### 1.1 一句话定义

Kakomon 是面向在日中国留学生的大学院入试（修考）过去问智能学习平台——把过去问拆到题，每题都讲透，对照参考书，问 AI 有据可查。

### 1.2 目标用户

| 维度 | 描述 |
|------|------|
| 人群 | 在日中国留学生，准备修士/大学院入试（修考） |
| 年龄 | 22–28 岁 |
| 设备 | iOS 手机为主，习惯碎片化学习（课间、通勤） |
| 目标校 | 东京大学、东京工业大学、京都大学、大阪大学、早稻田、庆应义塾、一桥、神户、名古屋、九州、北海道、东北、上智、同志社等 |
| 使用参考书 | 青本、赤本、マセマ系列、細野、演習大学院入試シリーズ |
| 痛点 | 过去问零散难找、解析质量参差、参考书对应不清、AI 回答缺乏题目上下文 |

### 1.3 核心产品循环

```
选定目标校
    ↓
浏览/搜索过去问题库
    ↓
打开单道题 → 读题 → 查标准解析（免费）
    ↓
对照参考书章节页码（免费）
    ↓
标记掌握情况（我会 / 模糊 / 不会）
    ↓
     ├→ 进入举一反三（同/相似/跨校题）
     ├→ 问 AI（消耗 Token 或 Pro 额度）
     └→ 论坛讨论本题
    ↓
弱点地图更新 → 下次推荐更精准
```

#### K3 题目详情页 · 完整段落顺序

```
① StatusBar + AppHeader（返回 / 大学·年份 / 书签 / 更多）

② 元数据卡
   大学名 · 研究科 · 年份 · 科目 · 题号
   知识点芯片（蓝色 #标签）
   难度徽章 + 众包难度（X% 偏难 · N 票）

③ 题目正文
   数字化题目文本（中文，含日文关键词）
   数学公式占位块（点击查看原版图）
   [查看原版] [复制] 操作

④ 掌握情况
   三格：[✓ 我会] [? 模糊] [✗ 不会]
   当前状态说明文字

⑤ 众包难度投票
   [简单 X%] [适中 X%] [偏难 X%]

⑥ 标准解析（FREE 标记）
   Step 1 / Step 2 / Step 3 结构化步骤

⑦ 参考书对应章节（FREE 标记）
   书目卡 × 3（完全同题 / 同考点 / 相似解法）
   每卡：书名 · 章节 · 页码 · AI 改写摘要
   [复制页码] [翻到这页]

⑧ AI 扩展讲解（PRO 锁定，模糊预览）
   为什么常出现在东大修考
   可迁移题型
   常见错误

⑨ 举一反三（三级关联）
   L1 同题（绿色）
   L2 相似考点（蓝色）
   L3 跨校相似题（紫色，Free 仅预览 2 题）

⑩ 论坛关联卡
   X 条相关讨论 → 跳转论坛

⑪ 底部悬浮栏（覆盖在 BottomNav 上方）
   [论坛] [✦ 问这道题  免费1/1 | 消耗1Token]
```

#### 众包难度校准规则

- 用户答题后可投票：简单 / 适中 / 偏难
- 显示百分比 = 该选项票数 / 总票数
- 后端每次更新投票后返回新比例，前端实时刷新

#### 学习圈（Study Circle）详细规格

学习圈是类 QQ 群的备考小组，与论坛帖子独立入口。

```
群组卡片
  [emoji] 群名称
  目标校 / 科目
  成员数 · 日活 · 今日任务一句话

群详情标签页
  ├ 消息（默认）── 气泡消息流，置顶任务/题目附件 特殊渲染
  ├ 成员 ── 成员列表 + 角色（群主/成员）+ 进度
  └ 日程 ── 活动列表（线上/线下 备考 session）

消息气泡特性
  普通文字 | 题目附件卡 | 系统消息
  长按 → emoji 快速反应
  置顶消息以 [pin] 标记在顶部

快捷发送芯片
  [今日做了X道] [谁有Y大Z年资料?] [明天集体自习] [打卡] [分享错题]
```

群组 scope 分类：`school+subject` / `school` / `subject` / `experience`

#### 帖子类型

| type | 中文 | 特征 |
|------|-----|------|
| `question_discussion` | 题目讨论 | 关联题目卡，支持已采纳 |
| `material_request` | 资料互助 | 求助/已解决状态机 |
| `experience` | 合格经验 | 运营验证徽章 |
| `study_circle` | 同校备考 | 线下/线上活动入口 |

#### 资料互助状态机

```
求助中(0) → 有人响应(1) → 协商中(2) → 已采纳(3)
```

### 4.2 解锁逻辑

```
功能访问检查（伪代码）

canUseAiExtended(user) → user.isPro

canAskAi(user) →
  user.isPro
  OR user.freeAiRemaining > 0
  OR user.tokenBalance > 0

canSeeL3Related(user) →
  user.isPro ? "全部" : "预览前 2 题"
```

### 4.3 贡献积分机制

- 用户上传过去问或参考书索引 → 运营审核 → 发放贡献积分

## 六、版权与参考书处理原则

- ✅ 显示书名、章节、页码范围
- ✅ 显示 AI 改写的简短方法摘要（非原文）
- ✅ 显示匹配理由
- ✅ 提供「复制页码」按钮
- ❌ 不显示完整扫描页面
- ❌ 不逐字引用参考书解答
- ❌ 不上传或分发受版权保护的内容
